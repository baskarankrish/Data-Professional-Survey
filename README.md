# Data Professional Survey Breakdown – Power BI Dashboard

## 1. Project Overview

This project explores the global data professional landscape through an interactive Power BI dashboard.

The analysis focuses on salary distribution across job roles, programming language preferences, gender-based salary comparisons, work-life balance and job satisfaction.

The dashboard presents survey data through interactive visualisations, helping users explore workforce trends and understand different aspects of careers in the data industry.

## Key Findings and Insights

- **Survey Demographics:** The survey included 630 respondents, with an average age of 29.87 years.
- **Salary by Job Role:** Data Scientists recorded the highest average salary, followed by Data Engineers and Data Architects.
- **Programming Language Preferences:** Python was the most preferred programming language among survey respondents, significantly ahead of other languages.
- **Work-Life Balance:** Respondents reported an average work-life balance score of 4.76 out of 10, indicating room for improvement.
- **Salary Satisfaction:** The average salary satisfaction score was 4.27 out of 10, highlighting relatively low satisfaction with compensation.
- **Salary Comparison by Gender:** Female respondents recorded a slightly higher average salary than male respondents within the surveyed population.

## 2. Project Objectives

The main objectives of this project were to:

- Analyse salary distribution across different data-related job roles.
- Explore programming language preferences among data professionals.
- Examine salary comparisons by gender.
- Understand the geographical distribution of survey respondents.
- Explore work-life balance and salary satisfaction.
- Present key workforce metrics through an interactive dashboard.

## 3. Tools and Technologies

## 4. Data Preparation and Transformation

The project involved preparing raw survey responses for analysis.

Key activities included:

- Cleaning and organising survey responses.
- Standardising inconsistent salary formats.
- Transforming data using Power Query.
- Creating calculated measures using DAX.
- Preparing data for dashboard visualisation.

## 5. Dashboard Overview

The interactive dashboard covers the following areas:

- **Survey Respondents:** Number of survey participants and their geographical distribution.
- **Average Salary by Job Title:** Comparison of average salaries across data-related roles.
- **Programming Language Preferences:** Exploration of the most popular programming languages.
- **Average Salary by Gender:** Comparison of average salaries across gender categories.
- **Work-Life Balance:** Survey-based work-life balance satisfaction score.
- **Salary Happiness:** Survey-based salary satisfaction score.
